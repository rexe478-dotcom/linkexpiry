# ClaimIt Style Guide

## Typography

Use one modern sans-serif font family where possible.

Suggested hierarchy:

Product name: 18--20px

Page heading: 24--30px

Section heading: 16--20px

Body: 14--16px

Secondary text: 13--14px

Labels: 13--14px medium

Avoid oversized typography.

------------------------------------------------------------------------

## Spacing

Use a consistent spacing scale.

Prefer generous whitespace around major sections.

Forms should not feel cramped.

Do not create excessive vertical gaps.

------------------------------------------------------------------------

## Borders

Use subtle borders.

Inputs: 1px neutral border.

Cards/panels: 1px subtle border where needed.

Avoid heavy outlines.

------------------------------------------------------------------------

## Radius

Use moderate corner radii.

Avoid making every element a giant pill.

Buttons may have modest rounding.

Inputs may have modest rounding.

------------------------------------------------------------------------

## Shadows

Use little or no shadow.

If a shadow is necessary, keep it subtle.

Do not use floating/glowing cards.

------------------------------------------------------------------------

## Buttons

Primary button: clear label compact height strong contrast visible
hover/focus state

Secondary button: neutral outlined or lightly filled

Do not make every button visually primary.

------------------------------------------------------------------------

## Forms

Every field needs a visible label.

Use helpful placeholders sparingly.

Show concise validation messages.

Never use placeholder text as the only label.

------------------------------------------------------------------------

## Statuses

Active: neutral/accent state

Success: restrained green

Full: neutral information state

Error: restrained red

Do not rely on color alone.

------------------------------------------------------------------------

## Sensitive Data

Account numbers should be masked by default in the creator interface.

Example:

\*\*\*\*\*\*\*\*6789

A deliberate reveal action may show the full value if authorized.

Never display account numbers publicly.

------------------------------------------------------------------------

## Responsive Rules

At 320px: - no horizontal page scrolling - inputs fit within viewport -
buttons remain usable - text wraps naturally

At desktop: - keep content focused - avoid full-width layouts unless
useful - preserve visual hierarchy

------------------------------------------------------------------------

## Accessibility

Maintain: - visible focus - adequate contrast - semantic controls -
keyboard navigation - clear labels - useful error messages -
screen-reader-friendly dynamic states

------------------------------------------------------------------------

## Anti-AI-Slop Checklist

Before finalizing, remove:

-   gradients
-   excessive cards
-   excessive pills
-   fake statistics
-   decorative blobs
-   unnecessary icons
-   oversized hero text
-   excessive shadows
-   generic illustrations
-   flashy colors
-   unnecessary animations

The design should feel quiet, precise, and useful.
